급여뚝딱 계정 삭제

급여뚝딱은 '팀 연동'을 켠 경우에만 계정이 만들어집니다. 팀 연동을 쓰지 않으셨다면 계정이 없으며, 앱을 삭제하면 모든 데이터가 함께 사라집니다.

앱에서 직접 삭제하기 (권장)

  1. 급여뚝딱 앱을 엽니다
  2. 아래쪽 관리 탭 → 팀 연동 카드로 이동합니다
  3. 맨 아래 계정 삭제를 누릅니다
  4. 안내를 확인하고 두 번 확인하면 즉시 삭제됩니다

무엇이 지워지나요

서버에서 즉시 삭제되는 것
  • 카카오 로그인 계정 정보(회원번호·닉네임)
  • 내가 만든 팀과 초대코드
  • 팀원들의 소속 정보
  • 팀원들이 보낸 출결 신고 전부
  • 팀원에게 보낸 급여명세서와 공유한 달력 전부 (팀원 앱에 이미 받아 둔 사본은 그 팀원 기기에 남습니다)
지워지지 않는 것
  • 휴대전화 안에 저장된 직원·급여 기록 — 임금 지급 근거가 되는 기록이라 앱이 임의로 지우지 않습니다. 직접 지우시려면 앱을 삭제하거나 기기 설정에서 앱 데이터를 삭제하세요.
  • 이미 내보낸 Excel·PDF·백업 파일 — 기기나 보내신 곳에 남아 있습니다

계정 삭제는 되돌릴 수 없습니다. 팀원들이 보낸 출결 신고도 함께 사라지므로, 필요하시면 먼저 정산·문서 탭에서 자료를 내보내 두세요.
